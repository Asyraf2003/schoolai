## Semantic, state and fallback contracts

Hero content, navigation, locale form and PPDB remain server-rendered and
usable before preparation. No-JS leaves the full page readable and scrollable.
Poster is visible before media; video failure cannot gate semantic access.
Reduced motion preserves static sections and explicit media/audio intent.

States distinguish shell-ready, section-preparing, prepared, fallback-ready,
active, suspended and disposed. A deadline may select a real static fallback;
it must not relabel incomplete enhancement as ready. Error/abort must release
scroll and preserve section access. Progress counts settled readiness work.

Gate applies only to first journey preparation; PPDB/navigation/focus are never
inert or blocked. Existing modal/navigation scroll ownership must be respected.
Restored positions and hash/anchor intent cannot be trapped at Hero. Persisted
pagehide suspends; pageshow resumes without duplicates; permanent exit disposes.
Locale POST + redirect suspends outgoing work and reconstructs from new lang/dir.

## Browser, budget and proof

Feature detection, current Chromium and WebKit; static fallback remains valid
when IO/RO/animation/media capability is absent. No UA fork. No-JS/no-WebGL,
keyboard, touch, focus restoration, 200% zoom and reduced motion remain usable.

Initial path adds zero cursor/renderer readiness dependencies; only active Hero
media warms after shell paint. Hidden slide media remains deferred. Preparation
is sequential and yields to browser; distant media is not bulk downloaded.
Inactive/hidden work cannot run a continuous frame/video loop. Native video
metadata/range behavior is measured, not asserted as a fixed buffer size.

Reject LCP/input/visual regression against ≥3 comparable baseline samples.
Attribute network, JS, decode, layout, style, paint and compositor separately.
Field CWV requires field data; local traces cannot certify it.
Source ≤200 lines; no anonymous overrides or duplicate readiness controllers.

Each map runs focused/new behavior tests, relevant regressions, build, structure,
diff and full PHP at merge. Runtime proof follows the DOD matrix and records
exact browser/profile/SHA/tool and unavailable gates truthfully.
